fork / wait

pid_t f = fork();
if (f < 0) perror("fork");
else if (f == 0) {
  // child: f=0
  exit(0);
} else {
  // parent: f=child PID
  wait(0);
}

fork copies memory, not shared.
zombie = child ended, parent not wait.

exec

pipe

- no reader => SIGPIPE/error

FIFO

mkfifo("f", 0600);
open("f", O_RDONLY);
open("f", O_WRONLY);
unlink("f");

FIFO = named pipe; unrelated processes.
data in kernel buffer, not disk file.
open read-only waits for writer.
open write-only waits for reader.
2-way communication => use 2 FIFOs.

pthread

void *f(void *arg){ return NULL; }
pthread_t th[N];
pthread_create(&th[i],NULL,f,arg);

Mutex / Critical

pthread_mutex_t m;
pthread_mutex_init(&m,NULL);
pthread_mutex_lock(&m);
// critical section only
pthread_mutex_unlock(&m);
pthread_mutex_destroy(&m);

critical section = shared data access needing protection.
race = result depends on scheduling.
do not lock whole function if only n++ needs lock.

Condition Var

pthread_cond_t c;
pthread_cond_init(&c,NULL);

pthread_mutex_lock(&m);
while (condition_bad)
  pthread_cond_wait(&c,&m);
// work
pthread_cond_signal(&c);
pthread_mutex_unlock(&m);

cond_wait unlocks m while sleeping,
then re-locks before return. Use while.

Sem / Barrier

sem_t s;
sem_init(&s,0,value);
sem_wait(&s); // if 0 => block
sem_post(&s); // increment/wake one
sem_destroy(&s);

barrier:
pthread_barrier_init(&b,NULL,N);
pthread_barrier_wait(&b);
pthread_barrier_destroy(&b);

barrier count = threads that must arrive.
count 1 => passes immediately.

RWLock / Deadlock

pthread_rwlock_rdlock(&rw); // many readers
pthread_rwlock_wrlock(&rw); // one writer
pthread_rwlock_unlock(&rw);
rdlock only if no modification.

Deadlock conditions:
mutual exclusion
hold and wait
no preemption
circular wait
Prevent: same global lock order.

High-Frequency Traps

sed needs g for all matches on line. | shell * differs from regex *
exec success => no following code; exec fail => following code runs.
pipe made in child cannot be used by parent if parent did not inherit it.
FIFO single stream not good for bidirectional communication.
different mutexes do not protect same shared variable.
cond_wait signal is only hint; condition can change before waiter resumes.
sem_wait on 0 => RUNNING -> WAITING; sem_post wakes.
barrier N must divide/fit number of threads reaching it, else hang.

OS Cheat Sheet 2/2 - Theory, Memory, FS, Cache

Process / CPU Virt

process = OS abstraction of running program.
CPU virtualization = time-sharing CPU.
PCB = process state, registers, PID,
scheduling info, memory info.

user mode = restricted program
kernel mode = privileged OS
trap/syscall = controlled entry to kernel
timer interrupt = OS regains CPU
context switch = save old, restore next

Process States

RUNNING = on CPU
READY = can run, waits CPU
WAIT/BLOCKED = waits I/O/event

READY -> RUNNING: scheduled
RUNNING -> READY: preempted/timer
RUNNING -> WAIT: blocking call/read/wait/sleep/I/O
WAIT -> READY: event done
I/O path: RUN -> WAIT -> READY -> RUN

Scheduling

turnaround = completion - arrival
response = first_run - arrival
waiting = turnaround - runtime

FIFO: simple, convoy effect.
SJF: best avg turnaround if lengths known.
STCF: preemptive shortest remaining.
RR: good response, worse turnaround, ctx overhead.
MLFQ: priority queues, learns behavior.

MLFQ / Deadlock

MLFQ:
higher priority runs first
same priority => RR
new jobs start top
use full allotment => move down
periodic boost to top => no starvation

deadlock = wait forever cycle
4 cond: mutex, hold&wait, no preempt, circular wait
fix: lock resources same order everywhere

Memory Basics

address space = process view of memory
translation: virtual addr -> physical addr

base+bounds:
if VA < bounds => PA = base + VA
else trap/protection fault

code = instructions, r/x
heap = malloc/calloc/realloc, grows up
stack = calls/local vars/params/ret addr, grows down

Segmentation

segmentation = one base+bounds per logical segment:
code, heap, stack
segment selected by high VA bits
stack grows downward => negative offset idea

external fragmentation:
free memory exists but split into holes.
Segmentation = variable-size chunks => external fragmentation.

Paging

paging = virtual memory cut into pages;
RAM cut into same-size frames.
page table maps VPN -> PFN.

VPN = VA / page_size
offset = VA % page_size
PA = PFN * page_size + offset

No external fragmentation.
Possible internal fragmentation + page table overhead.

TLB / Page Fault

TLB = cache of address translations.
TLB hit => fast VPN->PFN.
TLB miss => consult page table.

present bit 0 => page not in RAM => page fault.
OS loads page from disk.
dirty bit M=1 => written, eviction needs disk write.
reference bit R=1 => used recently.

Cache Idea

Disk = huge slow warehouse.
RAM = small fast desk/cache.
hit = page already in RAM.
miss/page fault = fetch from disk.
RAM full => evict victim page.

AMAT = hit_time + miss_rate * miss_penalty
Tiny miss rate bad if miss penalty huge.

Replacement

OPT/MIN: evict page used farthest in future; theoretical.
FIFO: evict oldest loaded; can have Belady anomaly.
LRU: evict least recently used; locality; no Belady anomaly.
Clock: approximate LRU with R/use bit.

Belady anomaly = more frames can cause more misses (FIFO).

NRU Victim

NRU uses R(reference) and M(modified/dirty).
Best victim = cheap + unlikely needed.

victim priority:
1 (R=0,M=0) not used, clean
2 (R=0,M=1) not used, dirty
3 (R=1,M=0) used, clean
4 (R=1,M=1) used, dirty

clean evict = no disk write; dirty evict = write back.

Cache Organization

direct mapped:
each block has one possible slot; fast, collisions/trashing.

fully associative:
block can go anywhere; flexible, search expensive.

set associative:
cache split into sets; block maps to one set,
can use any line inside set.
set = block_address % nr_sets

Free Space

external fragmentation = free space split into holes.
header before block stores size/metadata.
free(ptr) finds header at ptr - sizeof(header).
allocator searches requested_size + header_size.

splitting = big free block -> allocated + rest free.
coalescing = merge adjacent free blocks after free.

Placement

first-fit: first block big enough; fast; holes near start.
best-fit: smallest big enough; slow full search; tiny holes.
worst-fit: largest block; slow full search.
buddy: powers of 2; fast split/merge with buddy; internal fragmentation.

Filesystem

file = bytes.
directory = filename -> inode number.
inode = metadata + block pointers.
metadata: type, permissions, owner, size,
timestamps, link count, data block pointers.

superblock: FS metadata: size, nr blocks/inodes,
free block/inode info, layout/config.

Inode Formula

Linux-style:
0-9 direct pointers
10 single indirect
11 double indirect
12 triple indirect

B = block size, A = pointer size
N = B/A pointers per block
single = N blocks
double = N^2 blocks
triple = N^3 blocks
max = (10 + N + N^2 + N^3) * B

Links

hard link = new directory entry to same inode.
same filesystem/partition only.
rm/unlink removes name + decrements link count.
data freed when link count=0 and no process has file open.

symlink = separate file containing path.
Can cross filesystems; can dangle.

RAID

RAID 0: striping; fast/full capacity; no redundancy.
RAID 1: mirroring; reliable; ~50% usable; fast reads.
RAID 4: dedicated parity; tolerates 1 disk failure; parity bottleneck.
RAID 5: distributed parity; tolerates 1 disk failure; removes dedicated parity bottleneck.

small parity write: read old data + old parity,
write new data + new parity.

Do Not Forget

Process vs thread: process isolated memory, good for exec/fault isolation; thread shares memory, cheaper communication.
RUN -> WAIT when blocking; WAIT -> READY when event done, not directly RUN.
pthread_join can block caller => RUNNING -> WAITING.
Page loading: demand paging = load page when first needed/page fault; locality may load neighbors/prefetch.
Segmented-paged: segments split into pages; segment table + page table per segment.
Hard link cannot point to inode from another filesystem.
If O_CREAT used with open, include permissions mode.
read/write return bytes processed; may be less than requested.
