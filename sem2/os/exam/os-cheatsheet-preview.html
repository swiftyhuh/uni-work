UNIX Basics

Kernel mode: privileged, hardware access.
User mode: normal programs.
System call: user program asks kernel service.

File descriptors:
0 stdin
1 stdout
2 stderr

fork / wait / exit

pid_t f = fork();
if (f < 0) perror("fork");
else if (f == 0) {
    // child
    exit(0);
} else {
    // parent, f = child PID
    wait(0);
}
wait(&status);
WIFEXITED(status)
WEXITSTATUS(status)

fork Traps

fork returns:
0 in child
child PID in parent
-1 on error

After fork, both continue after fork line.
Memory is copied, not shared like threads.
Zombie = child ended, parent not wait.
Orphan = parent died, child adopted.

exec*

execl(path, argv0, arg1, ..., NULL);
execlp(prog, argv0, arg1, ..., NULL);
execv(path, argv_array);
execvp(prog, argv_array);

execlp("ls","ls","-l",NULL);
execvp(argv[1], argv+1);
Success: same PID, old code replaced, code after exec not run. Failure: returns -1.

pipe

int p[2];
pipe(p);
p[0] read end
p[1] write end

write(p[1], &x, sizeof x);
read(p[0], &x, sizeof x);
Create pipe before fork. Close unused ends.

pipe Behavior

read empty pipe:
- writer open => blocks
- all writers closed => returns 0 EOF

write pipe:
- no reader => SIGPIPE / error
- full pipe => blocks

FIFO

#include <sys/stat.h>
#include <fcntl.h>

mkfifo("f", 0600);
int r = open("f", O_RDONLY);
int w = open("f", O_WRONLY);
read(r, &x, sizeof x);
write(w, &x, sizeof x);
close(r); close(w);
unlink("f");

FIFO Traps

FIFO = named pipe.
Works for unrelated processes.
Data not stored on disk; kernel buffer.

open(O_RDONLY) waits for writer.
open(O_WRONLY) waits for reader.
Use 2 FIFOs for bidirectional.
One FIFO both ways = same stream/confusion.

dup / dup2

dup(fd) duplicates fd to lowest free fd.
dup2(oldfd, newfd):
newfd now points where oldfd points.

dup2(fd, 1);     stdout -> file
dup2(p[1], 1);   stdout -> pipe write
dup2(p[0], 0);   stdin <- pipe read

int saved = dup(1);
dup2(saved, 1);

popen

FILE *fp = popen("ps -ef", "r");
char line[256];
while (fgets(line, sizeof line, fp))
    printf("%s", line);
pclose(fp);
Use pclose, not fclose: command is child process, status must be collected.

OS Written Exam Cheat Sheet - Threads + OS Theory

pthread create/join

#include <pthread.h>

void *f(void *arg) {
    return NULL;
}

pthread_t th;
pthread_create(&th, NULL, f, arg);
pthread_join(th, NULL);
Thread function returns void *. Args passed as void *.

Passing Args

int id[N];
pthread_t th[N];

for (int i=0;i<N;i++) {
    id[i] = i;
    pthread_create(&th[i], NULL, f, &id[i]);
}

void *f(void *arg) {
    int id = *(int *)arg;
    return NULL;
}
Do not pass &i in loop if all threads share same i.

Mutex

pthread_mutex_t m;
pthread_mutex_init(&m, NULL);

pthread_mutex_lock(&m);
// critical section
pthread_mutex_unlock(&m);

pthread_mutex_destroy(&m);
Lock only important zone, not whole function. Protect shared writes/read+write.

Condition Variable

pthread_cond_t c;
pthread_cond_init(&c, NULL);

pthread_mutex_lock(&m);
while (condition_bad)
    pthread_cond_wait(&c, &m);
// do work
pthread_cond_signal(&c);
pthread_mutex_unlock(&m);
cond_wait unlocks mutex while sleeping, then re-locks before returning. Always use while.

Semaphore

#include <semaphore.h>
sem_t s;
sem_init(&s, 0, value);

sem_wait(&s); // decrement or block
// inside
sem_post(&s); // increment / wake

sem_destroy(&s);
Value = how many may enter simultaneously.

Barrier

pthread_barrier_t b;
pthread_barrier_init(&b, NULL, N);

pthread_barrier_wait(&b);

pthread_barrier_destroy(&b);
All N threads must arrive before any passes. Count 1 = no real wait.

RW Lock

pthread_rwlock_t rw;
pthread_rwlock_init(&rw, NULL);

pthread_rwlock_rdlock(&rw); // many readers
pthread_rwlock_wrlock(&rw); // one writer
pthread_rwlock_unlock(&rw);

pthread_rwlock_destroy(&rw);
If code modifies data, use write lock, not read lock.

Thread Traps

Race condition = result depends on scheduling.
Critical section = shared data access needing protection.
Deadlock possible if locks acquired in different order.
Mutex gives mutual exclusion, not ordering.
Cond gives wait-for-condition ordering.
Barrier gives all-wait-here synchronization.
Semaphore can count resources or order events.

Process States

NEW -> READY -> RUNNING -> TERMINATED
RUNNING -> READY: preemption/time slice over
RUNNING -> WAITING: blocking I/O/read/wait/sleep
WAITING -> READY: event/I/O done
READYcan run, waits CPU
RUNNINGon CPU
WAITINGblocked for event

Scheduling Metrics

turnaround = finish - arrival
response = first_run - arrival
waiting = turnaround - runtime
FIFOsimple, convoy effect
SJFbest avg turnaround if all jobs known
STCFpreemptive shortest remaining
RRfair, good response, context overhead
MLFQpriority queues, approximates job length

MLFQ Rules

Higher priority runs first.
Same priority: round-robin.
New job starts high.
Uses whole time slice => priority down.
Periodic priority boost prevents starvation.

Deadlock

Deadlock = processes/threads wait forever for each other's resources.
1mutual exclusion
2hold and wait
3no preemption
4circular wait
Prevent: break one condition.
Common: always lock resources same order.

Address Translation

Virtual address translated to physical address.
Goal: protection + illusion of private memory.

Base+bounds:
if VA < bounds: PA = base + VA
else trap/segmentation fault

Segmentation

Memory split into variable-size segments:
code, heap, stack.
Each segment has base + bounds.

Pros: protection, sharing, less waste inside segment.
Cons: external fragmentation.

Paging

Virtual memory split into pages.
Physical memory split into frames.
Page table maps VPN -> PFN.

VPN = VA / page_size
offset = VA % page_size
PA = PFN * page_size + offset
Paging removes external fragmentation, but creates page table memory cost.

TLB

TLB = cache for address translations.
Hit: fast translation.
Miss: must consult page table.

Effective access roughly:
hit_rate * fast + miss_rate * slow

Replacement Policies

OPTevict page used farthest in future; theoretical best
FIFOevict oldest loaded page; simple, can be bad
LRUevict least recently used; locality
Clockapprox LRU with reference bit
NRUuses R/M bits classes

Free Space

First-fitfirst big enough; fast, simple
Best-fitsmallest big enough; can create tiny holes
Worst-fitlargest hole; leaves medium holes
Coalescing = merge adjacent free blocks.
Splitting = divide bigger free block.

Cache

Direct mapped:
slot = block_address % cache_size
fast/simple, collision possible.

Fully associative:
block anywhere, needs search.

Set associative:
set = block_address % nr_sets
block placed in one set.
Locality: recently/nearby used data likely used again.

Filesystem

File = array of bytes.
Directory = mapping name -> inode number.
inode = metadata + pointers to data blocks.
Metadata: size, owner, permissions, times, block pointers.

inode / Links

Hard link: another name for same inode.
Cannot hard-link directories normally.
Cannot hard-link across filesystems.

Symbolic link: separate file containing path.
Can cross filesystems; can dangle.

unlink removes directory entry.
Data deleted when link count=0 and no open fd.

inode Blocks Formula

If block size B, pointer size P:
pointers_per_block = B / P

direct capacity = D * B
single indirect = (B/P) * B
double indirect = (B/P)^2 * B
triple indirect = (B/P)^3 * B

RAID

RAID 0striping; fast; no redundancy
RAID 1mirroring; redundancy; 50% usable capacity
RAID 4dedicated parity disk; parity bottleneck
RAID 5distributed parity; tolerates 1 disk failure

Highest-Frequency Written Exam Traps

exec success => no code after it; PID unchanged.
fork memory copied; threads share memory.
read empty pipe blocks if writer still open.
FIFO open blocks until other side opens opposite direction.
pipe created in child cannot be used by parent if parent did not inherit it.
popen must be closed with pclose.
cond_wait releases mutex while waiting and re-locks before returning.
cond_wait must be inside while, not if.
barrier count must equal threads that reach it.
read lock cannot protect writes.
deadlock prevented by fixed lock order.
RUNNING->READY = preemption; RUNNING->WAITING = blocking call.
hard link same inode; symlink path file.
