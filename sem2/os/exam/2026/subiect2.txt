EN: Protect the critical section in the program below.

Answer:

int n = 0;
pthread_mutex_t m;

void* f(void* v){
        pthread_mutex_lock(&m);
        if(n < 500) {
            n++;
        }

        if(n > 600) {
            n = 0;
        }
        pthread_mutex_unlock(&m);
        return NULL;
}

int main(){ 
    pthread_t t;
    pthread_mutex_init(&m, NULL);
    pthread_create(&t, NULL, f, NULL);
    pthread_join(t, NULL);
    pthread_mutex_destroy(&m);
    return 0;
}

RO: Care este diferenta dintre politicile de planificare SJF si FIFO/FCFS?
EN: What is the difference between the SJF and FIFO/FCFS scheduling policies?

Answer:
SJF (shortest job first) executa non-preemptiv, adica executa pana la capat sarcina cu cel mai mic timp de executie la momentul verificarii. FIFO/FCFS(first in first out/first come first serve) executa prima sarcina in coada, fara a compara timpii de executie a acestora.
