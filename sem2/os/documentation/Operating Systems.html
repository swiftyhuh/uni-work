Grading policy for practical tests/exams
  •   0 = The student cannot answer questions about the code, or the solution solves a different problem
  •   1 = Shell scripts have syntax errors or C code has compilation errors/warnings
  •   4 = Runtime crash
  •   7 = All of the above are OK but the implementation is not quite complete
  • 10 = Complete implementation and correct execution.

Re-examination Info
  • Re-exam options
    • Rw - Written re-exam. This has the same format as the written exams that you took in the normal examination period.
    • Rsh - UNIX Shell practical re-exam.
    • Rtp - UNIX Processes and threads practical re-exam.
  • Who should/can take which re-exams:
    • If you have insufficient attendances, you cannot take any of these re-exams. You need to take the class again next year.
    • If you have sufficient attendances, but no final grade, it means that some of your grades were too low or missing, so you must take those respective re-exams, and any others that you choose (you can take multiple exams on the same day).
    • If you have a final grade and want to improve it, you can take any of the exams you choose (you can take multiple exams on the same day).
