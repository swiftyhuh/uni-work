Manual Executions - Practical Work 3 - Problem 4

Algorithm implemented: Lowest cost walk using the dynamic programming matrix d[x][k] = minimum cost from s to x using exactly k edges.

Requirement: 2 manual executions (there is a walk / there is no walk) on a graph with 5 vertices and 10 edges.

Manual Execution 1 - There Is a Walk

Vertices: 0, 1, 2, 3, 4

Start: 0

End: 4

Edges (10):

(0,1) cost 2 (0,2) cost 5 (1,2) cost 1 (1,3) cost 4 (2,3) cost 1 (2,4) cost 7 (3,4) cost 2 (4,1) cost 3 (0,3) cost 9 (1,4) cost 8

Graph Drawing

0 ---> 1 ---> 2 ---> 3 ---> 4 | | | ^ | | +-----------> | | +-------------------> | +--------------------------> | 4 -------------------------> 1

Matrix d[x][k]

x \ k 0 1 2 3 4
0 0 - - - -
1 - 2 - 13 11
2 - 5 3 - 14
3 - 9 6 4 17
4 - - 10 8 6

Explanation

  • d[0][0] = 0 because cost from start to start with 0 edges is 0.
  • d[1][1] = 2 via edge (0,1).
  • d[2][2] = 3 via walk 0 → 1 → 2.
  • d[3][3] = 4 via walk 0 → 1 → 2 → 3.
  • d[4][4] = 6 via walk 0 → 1 → 2 → 3 → 4.
  • We inspect d[4][k] for k = 0 to 4. The minimum value is 6.

Result

Minimum Cost Walk: 0 → 1 → 2 → 3 → 4

Cost: 6

Manual Execution 2 - There Is No Walk

Vertices: 0, 1, 2, 3, 4

Start: 0

End: 4

Edges (10):

(0,1) cost 2 (1,2) cost 1 (2,0) cost 3 (1,0) cost 4 (2,1) cost 2 (0,2) cost 5 (3,4) cost 1 (4,3) cost 1 (3,3) cost 0 (4,4) cost 0

Graph Drawing

0 <--> 1 <--> 2 ^ | +-----------+ 3 <--> 4

Matrix d[x][k]

x \ k 0 1 2 3 4
0 0 - 6 6 9
1 - 2 7 5 8
2 - 5 3 8 6
3 - - - - -
4 - - - - -

Explanation

  • The graph consists of two disconnected components: {0, 1, 2} and {3, 4}.
  • The DP correctly explores cycle costs inside the {0, 1, 2} component as k increases.
  • Because no edge connects {0, 1, 2} to {3, 4}, d[4][k] stays undefined (-) for all values of k.

Result

Message: There is no walk.
