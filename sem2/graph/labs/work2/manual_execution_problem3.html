Manual Executions for Practical Work 2 - Problem 3

Task: find the connected components of an undirected graph using DFS.

This document follows the requirement from lab2.txt and the style of the teacher examples from manual_execution_lab2_path.pdf and manual_execution_lab2_connected.pdf.

Algorithm executed manually

For each vertex in order, if it is not in visited, start a DFS from it. The DFS puts all vertices of the current connected component in component_vertices. After the DFS ends, that component is added to result.

The implementation used in the program is iterative DFS with a stack.
